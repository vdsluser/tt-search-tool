# TT Rubber Scout

A reusable multilingual table-tennis rubber research workflow.

## Repository contents
- `SKILL.md` — research skill definition
- `references/` — source, query, scoring, and report rules
- `docs/index.html` — GitHub Pages dashboard for the current research result

## Current baseline
The first published report compares budget alternatives to a Viscaria setup using MX-K on FH and Rozena on BH.
